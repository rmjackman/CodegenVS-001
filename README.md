# CODEGEN and SOURCEGEN — Atari 8-bit Development Tools

Cross-development tools for Atari 8-bit computers based on the 6502 processor.

This project contains **CODEGEN** and **SOURCEGEN**, tools for working with Atari assembly-language source code. CODEGEN supports ATMAS II assembler syntax as well as syntax used by other assemblers.

The project is developed in C using Microsoft Visual Studio.

## Features and tools

- **CODEGEN** — assembly-language development and code generation for Atari 8-bit programs.
- **SOURCEGEN** — source-code generation and related development tools.
- **Disassembler** — tools for converting machine code back into assembly-language source.
- **ATMAS II compatibility** — support for ATMAS II assembler syntax, with support for syntax from other assemblers.
- **6502 development** — tools intended for the Atari XL/XE and related 6502-based development environment.

The repository includes C source files, a Visual Studio solution, assembler source files, and supporting utilities.

## Getting started

1. Browse the source files and the `6502 Source` directory to explore the project.
2. Open `CodegenVS-001.sln` in Microsoft Visual Studio.
3. Inspect the project configuration and source files before building.
4. Consult the included source files and documentation for details of the individual tools.

Build requirements and configuration may depend on the version of Visual Studio and the selected project settings.

## Intended audience

This project is intended for Atari 8-bit enthusiasts, 6502 assembly-language programmers, and developers interested in cross-development tools and classic Atari computing.
